Cache-Aligned SSARecord Memory Layout (16 Bytes)

Every SSA variable version created across all functions is recorded as a 16-byte fixed-size entry (§5.2.4).

u32 (4 Bytes)
orig_sym_id
u32 (4 Bytes)

u32 (4 Bytes)
version
u16 (2B)
flags
u8 (1B)
def_block
u8 (1B)
// SSARecord Struct Definition in Rust (src/core/types/ssa.rs)
#[repr(C)]
pub struct SSARecord {
    pub ssa_id: u32,        // Globally unique SSA ID within function
    pub orig_sym_id: u32,   // Symbol ID in STA of original variable
    pub def_stmt: u32,      // BP AST pre-order index (u32::MAX for phi)
    pub version: u16,       // Version number for orig_sym_id (0-based)
    pub flags: u8,          // IS_PHI:1, IS_PARAM_DEF:1, IS_FIELD_DEF:1, IS_RETURN_VAL:1, IS_CONST:1
    pub def_block: u8,      // Basic block ID (mod 256)
}
PhiRecord & PhiArg Specifications

Variable-length record inserted at CFG join points (§5.4):

// Header (12 Bytes)
ssa_id:    u32  // Target SSA ID
block_id:  u32  // Basic block where phi is placed
arg_count: u16  // Number of predecessor arguments (k)
orig_sym:  u16  // Symbol ID (mod 65536)

// PhiArg Array (8 Bytes each x arg_count)
pred_block_id: u32  // CFG predecessor block
arg_ssa_id:    u32  // Live SSA version from predecessor
DefUseCSR & CDGCSR Formats

Sparse compressed representations for O(1) navigability (§5.4):

// DefUseCSR: O(1) use enumeration per SSA variable
def_offsets: Vec<u32> // (n_ssa + 1) offset index
use_adj:     Vec<u32> // AST statement pre-order indices

// CDGCSR: Control Dependence Graph CSR
cd_offsets:  Vec<u32> // (n_blocks + 1) offset index
cd_adj:      Vec<u32> // Dependent basic block Y
cd_types:    Vec<u8>  // CD_EDGE_TRUE (0x01), CD_EDGE_FALSE (0x02)

Phase 5 Mandatory Invariants for Phase 6
Invariant 1: Single Assignment Property

∀ ssa_id v: |{stmt s : s defines v}| = 1. Every SSA variable has exactly one definition site recorded in SSARecord.def_stmt. Verified by asserting def-count per ssa_id equals 1.

Invariant 2: φ-Argument Count Completeness

For every φ-function in basic block B with k CFG predecessors: PhiRecord.arg_count == k, and PhiRecord.args has exactly one entry per predecessor of B.

Invariant 3: Def-Use CSR Completeness

∀ ssa_id v: Σ_{stmts s} [s uses v] == len(use_adj[def_offsets[v]..def_offsets[v+1]]). Every use recorded during renaming has a corresponding entry in DefUseCSR.

Invariant 4: SSA to TCA Traceability Seed

For every SSARecord where flags.IS_PHI == 0: def_stmt is a valid BP AST pre-order index. The source location is recovered via bpa.token_range(def_stmt) → token_ids → BI[token_id] in TCA.
