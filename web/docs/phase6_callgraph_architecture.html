⚡ 6.1 Mandate & Boundaries

Phase 6 assembles the inter-procedural skeleton of the SCPG. It resolves every call site in the BP AST (direct, virtual, interface, constructor, dynamic) to possible callee symbols using CHA and 1-CFA, runs Anderson points-to analysis, and extracts recursive cycles using Tarjan's SCC algorithm.

Inputs:  .bpa (AST), .sta (Symbols), .cfa (CFG), .ssa (SSA)
Output:  .cga (CallGraphArtifact binary file)
Header:  64-byte aligned header with ssa_hash & sta_hash links

📐 6.2 Formal Graph Definition

The Call Graph is defined as G_CG = (V_CG, E_CG) where V_CG is the set of callable symbols (methods, constructors, lambdas) and E_CG is the set of typed, annotated call edges.

Type CodeEdge Alphabet (Σ_CG)Dispatch Semantics
0x00CG_DIRECTStatic method call (Monomorphic)
0x01CG_SPECIALPrivate / Constructor / Super call
0x02CG_VIRTUALInstance method call (CHA/1-CFA)
0x03CG_INTERFACEInterface method call (Polymorphic)
0x04CG_CONSTRUCTORConstructor allocation call
0x05CG_DYNAMICLambda / Method Reference

🔍 6.3 Dispatch Resolution Algorithms

Resolution combines Class Hierarchy Analysis (CHA) with 1-CFA allocation-site sensitivity to bound virtual dispatch fan-out efficiently.

1. Direct/Special: STA symbol lookup (1 target)
2. 1-CFA Sensitivity: Inspect SSA receiver def_stmt (NN_NEW_EXPR)
3. CHA Fallback: Downward BFS over Symbol Table Type Hierarchy

🔄 6.4 Anderson Points-To Analysis

Inclusion-based constraint solver computing global points-to sets pts: SsaId -> Set<AllocTypeSymId> via worklist fixpoint propagation.

v^i = new T()   -> {alloc_T} ⊆ pts(v^i)
v^i = v^j (copy) -> pts(v^j) ⊆ pts(v^i)
v^i = phi(...)   -> pts(arg) ⊆ pts(v^i)
