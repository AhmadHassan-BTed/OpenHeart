Memoization ensures each ROBDD node is visited exactly once. Time: O(|ROBDD|). For a function with 500 nodes, #SAT is computed in ~500 hash lookups — sub-microsecond. Cyclomatic complexity V(G) = |E| - |B| + 2 = 6 - 5 + 2 = 3 for this CFG (stored separately as u16, never re-derived from the ROBDD).

Building f_paths = Φ_B0 ∧ Φ_B1 ∧ Φ_B2 ∧ Φ_B3 ∧ Φ_B4 requires 4 apply(AND, ...) calls. Each call is O(|f| × |g|) but in practice sub-linear because: (a) memoization avoids re-visiting identical (f,g) pairs, (b) terminal short-circuits prune many branches early, (c) the intermediate BDDs are small when using good variable ordering.

Phase 8 total: O(m × |ROBDD| × n_functions) — dominated by sifting. For 15K functions at avg 35 vars and 500 nodes: 15K × 35 × 500 = 262M operations ≈ 1.3 seconds. This is the most CPU-intensive phase after Phase 5 IFDS. It is embarrassingly parallelizable — each function's ROBDD is built independently in O(m × |ROBDD|) with no shared mutable state except the (lock-free) unique table.
