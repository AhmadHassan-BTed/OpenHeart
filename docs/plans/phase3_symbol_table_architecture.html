Why 5 passes and not 1?
Java allows forward references — class A on line 1 can extend class B declared on line 500. A single-pass resolver would attempt to resolve A's supertype before B's symbol exists. Pass 1 must complete across ALL files before Pass 3 can begin. This is not an engineering choice — it is a formal requirement of the grammar.
