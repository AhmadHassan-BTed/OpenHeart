LRU Cache invalidation strategy: keyed by (query_type:u8, params_crc:u64, scpg_hash:u32). A source edit changes scpg_hash → full cache flush on next get() call (lazy O(1): just stores new hash, clears lazily per-entry). Capacity: 512 entries. Typical hit rate for diagram tools: 90–98% (diagrams are re-requested as users scroll/resize).
