Phase 5 SSA algorithm: for variable sum (defined in B1, B3, B4): compute iterated dominance frontier DF⁺({B1,B3,B4}) = {B2, B5}. Insert φ(sum) at B2 (for loop-carried value) and φ(sum) at B5 (for if-else merge). This is Cytron et al.'s φ-placement theorem.
Loop analysis: back edge detection via DFS coloring, natural loop identification, and loop depth annotation.
Back edge detection algorithm: DFS colors each block White → Gray (on stack) → Black (done). An edge (u,v) where v is Gray is a back edge — v is still on the DFS stack, meaning v is an ancestor of u. Back edge (B3→B2) identifies B2 as a loop header. Natural loop = all blocks that can reach B3 without passing through B2, plus B2 itself = {B2, B3}.
