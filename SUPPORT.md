# Getting Support for OpenHeart

Thank you for exploring **OpenHeart**, maintained by **Ahmad Hassan (B-Ted)**. For support, questions, or issues, please use the following channels:

👉 **[Launch OpenHeart Web Studio Portal (GitHub Pages)](https://ahmadhassan-bted.github.io/OpenHeart/)**

---

## Community Support Channels

### 1. GitHub Discussions
For general questions, architecture discussions, ideas, and usage guidance:
- Visit [GitHub Discussions](https://github.com/AhmadHassan-BTed/OpenHeart/discussions).

### 2. Issue Tracker
For bug reports, unexpected errors, or feature requests:
- Check [docs/status.md](docs/status.md) first: many limitations (unsupported languages, template diagram views, partial analyses) are already documented there.
- Search existing [GitHub Issues](https://github.com/AhmadHassan-BTed/OpenHeart/issues) before opening a new issue.
- Please use the provided issue templates when submitting requests.

---

## Security Vulnerabilities

For security concerns or sensitive vulnerability disclosures:
- Please refer to [SECURITY.md](SECURITY.md).
- Do not open a public issue for a vulnerability.
