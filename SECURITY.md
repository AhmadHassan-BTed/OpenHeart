# Security Policy

## Supported Versions

Only the latest major release of **OpenHeart** receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

We take the security of **OpenHeart** seriously. If you discover a security vulnerability, please do **NOT** open a public GitHub issue.

Instead, please report vulnerabilities by emailing our security team at **security@openheart.dev** or using GitHub's Private Vulnerability Reporting feature.

### Information to Include

To help us triage and resolve the issue quickly, please include:
- A description of the vulnerability and potential impact.
- Step-by-step instructions to reproduce the issue or a proof-of-concept payload.
- Affected components (e.g. Phase 1 `.tca` binary parser, FNV-1a interner, tree-sitter adapter).
- Any proposed remediation or patch.

### Response Timeline

- **Acknowledgement**: Within 24 hours.
- **Triage & Assessment**: Within 72 hours.
- **Fix & Security Release**: Target within 14 days depending on severity.

Thank you for helping keep OpenHeart secure!
